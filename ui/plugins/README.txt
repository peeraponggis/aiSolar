============================================================
  LocalAI Chat - Plugin System (ระบบปลั๊กอิน)
============================================================

** ต้องเปิดแอปผ่าน http://127.0.0.1:11435/ (ไม่ใช่ file://) **
   เปิดด้วย lung_pee.bat จะเปิดให้อัตโนมัติ

วิธีเพิ่มปลั๊กอิน:
  1) สร้างไฟล์ .js ในโฟลเดอร์นี้ (D:\LocalAI\ui\plugins\)
  2) เพิ่มชื่อไฟล์ใน plugins.json  { "file": "ชื่อ.js", "enabled": true }
  3) รีโหลดหน้าแชท (F5)

โครงสร้างปลั๊กอิน:
  LocalAI.register({
    name: "ชื่อปลั๊กอิน",
    version: "1.0",
    init() {
      // โค้ดตอนโหลด - ลงทะเบียนปุ่ม/คำสั่ง/hook ที่นี่
    }
  });

------------------------------------------------------------
 LocalAI API ที่ใช้ได้
------------------------------------------------------------
  addButton(label, onClick, title)
      -> เพิ่มปุ่มบนแถบบน  เช่น addButton('🔧', ()=>{...}, 'คำอธิบาย')

  addCommand(name, fn)
      -> คำสั่งพิมพ์ในแชท เช่น addCommand('/สรุป', (arg)=>{ ...; return true })
         fn รับ arg (ข้อความหลังคำสั่ง), return true = จัดการเองไม่เรียกโมเดล

  onSend(fn)
      -> hook ก่อนส่ง  fn(text) -> return false ยกเลิก / return string แก้ข้อความ

  onReply(fn)
      -> hook หลังโมเดลตอบ  fn(text, conversation)

  insertInput(text)          -> แทรกข้อความในกล่องพิมพ์
  addAssistantMessage(text)  -> เพิ่มข้อความฝั่ง AI (ไม่เรียกโมเดล)
  send(text)                 -> ส่งข้อความแทนผู้ใช้ (เรียกโมเดล)
  speak(text)                -> อ่านออกเสียง
  addKnowledge(text, source) -> เพิ่มเข้าคลังความรู้ RAG
  log(msg, level)            -> เขียน console ('info'|'ok'|'warn'|'err')
  cfg                        -> อ่านค่า config (สำเนา อ่านอย่างเดียว)
