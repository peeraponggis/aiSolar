============================================================
  LocalAI Feed — Browser Extension
  ข่าว AI/เทคโนโลยี + Social mentions -> เข้ากรอบใน chat.html
============================================================

ทำอะไร:
  1) ดึงข่าว AI/โมเดล/เทคโนโลยี จาก RSS ฟรี (Google News ไทย+อังกฤษ, Hacker News)
     -> อัปเดตอัตโนมัติทุก 30 นาที
  2) อ่าน "mentions" จากแท็บโซเชียลที่คุณล็อกอิน+เปิดค้างไว้
     (Facebook / YouTube / TikTok) เฉพาะโพสต์ที่มีคำที่ติดตาม
     *ไม่เปิดแท็บ = ไม่มีข้อมูล / ไม่แตะรหัสผ่าน ใช้ session เดิม*

คำที่ติดตามเริ่มต้น: peerapong, aisolar, ai, พีระพงษ์, อ.พี
  (แก้ได้ในหน้าแชท -> ระบบจะส่ง keyword ให้ extension เอง
   หรือแก้ค่า DEFAULT_KEYWORDS ใน background.js)

------------------------------------------------------------
 วิธีติดตั้ง (ครั้งเดียว) — Chrome หรือ Edge
------------------------------------------------------------
 1) เปิด  chrome://extensions   (หรือ edge://extensions)
 2) เปิดสวิตช์ "Developer mode" (มุมขวาบน)
 3) กด "Load unpacked" -> เลือกโฟลเดอร์  D:\LocalAI\extension
 4) คลิกที่ extension -> Details -> เปิด
      "Allow access to file URLs"   (สำคัญ! ให้ทำงานกับ chat.html ที่เปิดแบบ file://)
 5) เปิด chat.html (ผ่าน Start-LocalAI.bat) -> กดปุ่ม 📰 บนแถบบน -> กด ⟳

 * ย้าย HDD ไปเครื่องอื่น: ทำขั้นตอน 1-4 ซ้ำที่เครื่องใหม่ (extension ผูกกับเบราว์เซอร์)

------------------------------------------------------------
 การใช้งาน
------------------------------------------------------------
  - ปุ่ม 📰 ในหน้าแชท -> เปิดกรอบ "ข่าว & Mentions"
  - แท็บ: ทั้งหมด / ข่าว AI-Tech / Mentions
  - คลิกการ์ด -> เปิดลิงก์ต้นทางไปอ่าน
  - จุดแดงบนปุ่ม 📰 = มีรายการใหม่

  Social mentions จะมีก็ต่อเมื่อ:
    - ติดตั้ง extension แล้ว + เปิดแท็บ Facebook/YouTube/TikTok ที่ล็อกอินไว้
    - เลื่อนดูฟีดในแท็บนั้น (extension อ่านสิ่งที่โหลดบนหน้า)

------------------------------------------------------------
 หมายเหตุ LINE
------------------------------------------------------------
  LINE เป็น "แอปเดสก์ท็อป" ไม่ใช่เว็บ -> browser extension อ่านไม่ได้
  ต้องใช้ตัวช่วยแยก (native helper) อ่านหน้าต่างแอป LINE ตอนเปิดอยู่
  ดูไฟล์  D:\LocalAI\line-watch\  (ถ้าติดตั้งส่วนนี้)

------------------------------------------------------------
 ความเป็นส่วนตัว
------------------------------------------------------------
  - extension อ่านเฉพาะหน้าที่เปิดอยู่ ไม่ส่งข้อมูลออกนอกเครื่อง
  - ข่าว/mentions เก็บใน storage ของเบราว์เซอร์ + ส่งเข้า chat.html เท่านั้น
