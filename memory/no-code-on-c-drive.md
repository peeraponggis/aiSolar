**ห้ามเขียนโปรแกรมหรือโค้ดใดๆ ลงในไดรฟ์ `C:\` โดยตรง** ไฟล์โปรแกรม/สคริปต์/โปรเจกต์ทั้งหมดต้องอยู่บน `D:\` (หรือไดรฟ์ของ external HDD ที่กำลังใช้)

**Why:** ผู้ใช้ทำงานจาก external HDD เพื่อความพกพา และต้องการให้ C: (ไดรฟ์ระบบ) สะอาด ไม่มีไฟล์งานปน

**How to apply:** เมื่อสร้างไฟล์โค้ด/โปรเจกต์ ให้วางไว้ใต้ `D:\` เสมอ. ข้อยกเว้นเดียวคือไฟล์โน้ต/ความจำ markdown ของระบบ `.claude` (ไม่ใช่โค้ด) ที่อาจอยู่ใน C: เพื่อให้ Claude เรียกใช้ข้ามเซสชันได้ — แต่ถ้าเลี่ยงได้ให้เก็บชุดพกพาไว้ที่ `D:\LocalAI\memory\` ด้วย. เกี่ยวข้องกับ [[git-worktree-workflow]] และ [[local-ai-portable-setup]]
