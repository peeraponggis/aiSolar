       Length_mm, Width_mm          ← ใช้จัดวางแผงบนผัง สำคัญที่สุด

@@6
   PV:
   - ใช้ค่า STC เป็นหลัก ค่า NOCT/NMOT ใส่ใน [NMOT_PARAMETERS]
     NMOT_Value_C = อุณหภูมิเซลล์ที่ NMOT/NOCT (เช่น 43±2°C → 43)
   - Warranty_Years = ปีรับประกันกำลัง (Power/Performance warranty)
     Product_Warranty_Years = ปีรับประกันตัวสินค้า (Product/Material warranty) อย่าสลับกัน
   - แผง Bifacial ใช้ค่า STC ด้านหน้า (Front side) ไม่ใช่ค่ารวม Bifacial gain
     Is_Bifacial = True เมื่อเอกสารระบุ Bifacial · ระบุชัดว่าหน้าเดียว (Monofacial/backsheet) = False
     ไม่กล่าวถึงเลย = ว่าง + [ไม่มีข้อมูล] (โปรแกรมถือว่าแผงหน้าเดียว)
     Bifaciality_Factor ใส่เป็นทศนิยม (80±5% → 0.8)
   - Max_Series_Fuse_Rating_A กับ Max_Reverse_Current_A เอกสารระบุค่าเดียว ให้ใส่ทั้งสองฟิลด์
   - ชื่อฟิลด์สัมประสิทธิ์อุณหภูมิใช้ Tk_Pmax_Pct_Per_C, Tk_Voc_Pct_Per_C, Tk_Isc_Pct_Per_C เท่านั้น
   - หน่วยของ Tk_* เป็น %/°C เอกสารที่ระบุ mV/°C หรือ mA/°C ต้องแปลง (ข้อ 4.7) และกำกับ CALCULATED
   - Power_Tolerance คัดตามเอกสาร เช่น "0/+5W" หรือ "0~+3%"
   - IAM_ASHRAE_b0 / IAM_Glass_Index_n ส่วนใหญ่ไม่อยู่ใน datasheet = ไม่มีข้อมูล (ห้ามคงค่า 0.05 / 1.526 ของแม่แบบ)
   - First_Year_Degradation_LID_Pct, Annual_Degradation_Rate_Pct อ่านจากกราฟ/ข้อความ Linear warranty
     เช่น "1% first year, 0.4% annual" → 1.0 และ 0.4 · Warranty_End_Power_Pct เช่น 87.4
@@7
   PV:
   - Vmp_V น้อยกว่า Voc_V และ Imp_A น้อยกว่า Isc_A
   - Vmp_V x Imp_A อยู่ในช่วง Pmax_Wp บวกลบ 3%
   - Module_Efficiency_Pct ประมาณ Pmax_Wp หาร (Length_mm x Width_mm หาร 1000000) หาร 10 บวกลบ 0.5
     ตรวจข้อนี้ไม่ได้เพราะไม่มีขนาดแผง = ขาดฟิลด์บังคับ ให้กลับไปหาใหม่
   - Tk_Voc และ Tk_Pmax ติดลบ, Tk_Isc เป็นบวก
   - Voc_V x จำนวนแผงที่คิดได้ ไม่ใช่หน้าที่ของไฟล์นี้ (โปรแกรมคิดเอง) ห้ามกรอกค่าสตริง

   [PV]
   Maximum Power / Peak Power / Rated Power / Pmax / Pmpp / Nominal Power → Pmax_Wp
   Open Circuit Voltage / Voc / Open-circuit Voltage                       → Voc_V
   Short Circuit Current / Isc / Short-circuit Current                     → Isc_A
   Maximum Power Voltage / Vmp / Vmpp / Voltage at Pmax / Rated Voltage    → Vmp_V
   Maximum Power Current / Imp / Impp / Current at Pmax / Rated Current    → Imp_A
   Module Efficiency / Efficiency / Panel Efficiency / STC Efficiency      → Module_Efficiency_Pct
   Temperature Coefficient of Pmax / Pmpp / Power / γ(Pmax)                → Tk_Pmax_Pct_Per_C
   Temperature Coefficient of Voc / β(Voc)                                 → Tk_Voc_Pct_Per_C
   Temperature Coefficient of Isc / α(Isc)                                 → Tk_Isc_Pct_Per_C
   NOCT / NMOT / Nominal Operating Cell Temperature                        → NMOT_Value_C
   Maximum System Voltage / System Voltage / Max. System Voltage           → Max_System_Voltage_V
   Maximum Series Fuse Rating / Max Fuse / Series Fuse                     → Max_Series_Fuse_Rating_A และ Max_Reverse_Current_A
   Power Tolerance / Output Tolerance / Power Sorting                      → Power_Tolerance
   Dimensions / Size / Module Size / Overall Size (L x W x H)              → Length_mm, Width_mm, Thickness_mm
   Weight / Module Weight                                                  → Weight_kg
   Bifaciality / Bifacial Factor / Rear side power ratio                   → Bifaciality_Factor
   Mechanical Load / Static Load / Wind Load / Snow Load (Front / Back)    → Max_Snow_Load_Pa (Front), Max_Wind_Load_Pa (Back)
   Power Warranty / Performance Warranty / Linear Warranty                 → Warranty_Years
   Product Warranty / Material Warranty / Workmanship Warranty             → Product_Warranty_Years
   First year degradation / Year 1 / Initial degradation                   → First_Year_Degradation_LID_Pct
   Annual degradation / Yearly degradation / Linear degradation            → Annual_Degradation_Rate_Pct
   Cell Type / Cell Technology / Solar Cells                               → Cell_Type
   No. of Cells / Cell Number / Cell Arrangement                           → Number_of_Cells, Cell_Configuration
   Junction Box / J-Box (IP)                                               → Junction_Box_IP_Rating
   Connector / Connector Type (MC4, MC4-EVO2)                              → Connector_Type
   Cable / Output Cable (mm², Length)                                      → Cable_Cross_Section_mm2, Cable_Length_mm
   Fire Rating / Fire Class / Application Class / Safety Class             → Fire_Rating, Safety_Class
@@11
   ฟิลด์ (PV)        ค่าที่ยอมรับ                         โปรแกรมใช้ทำอะไร
   Is_Bifacial       True / False (ไม่มีคำพูด)            คิดพลังงานด้านหลังแผง
   Cell_Type         คัดตามเอกสาร แต่ต้องมีคำใดคำหนึ่ง      แผง n-type ใช้ค่าเสื่อมต่างจาก p-type
                     ที่เอกสารใช้ เช่น "N-type TOPCon",
                     "HJT", "P-type PERC", "Monocrystalline"
   Power_Tolerance   "0/+5W" หรือ "0~+3%" (มีหน่วย W หรือ %) คิด Module quality loss
