ข. สะกดคีย์/หน่วย/ค่าข้อความที่ไม่ตรง (prompt เดิมไม่บอก ทำให้โปรแกรมเข้าใจผิดเงียบ ๆ)

   Battery_Coupling_Class  ต้องขึ้นต้น HV/LV · Battery_Voltage_Class ต้องมี HV/LV
   Off_Grid_Mode / AC_Coupling_Port  ต้องมีคำ Both/assist/stand · backup/gen/smart
   Max_Continuous_*_Power_kw (BAT)   ตัว w เล็กตามแม่แบบ (โปรแกรมรับ _kW ด้วย)
   ค่าข้อความที่มี " ;" หรือ " #"     โปรแกรมตัดทิ้งตั้งแต่ตรงนั้น → 3.4 ห้ามใช้ ให้คั่นด้วยจุลภาค

จ. ช่องว่างฝั่งโปรแกรม (แก้ด้วย prompt ไม่ได้ — อยู่ในแผนรออนุมัติ)
   1. ค่าจำลอง/รายงาน (ประสิทธิภาพรายภาระ · derating · เสื่อม · IAM · bifacial · tolerance · รับประกัน · IP)
      อ่านจากคลังในตัวโปรแกรม (datasheetExtras) เท่านั้น ไม่อ่านจากไฟล์ .txt ที่นำเข้า
      ทดสอบจริง: CS6K-300MS ในไฟล์มี Warranty 25 ปี / Product 10 ปี แต่คลังในตัวเป็น null → รายงานไม่แสดง
      รุ่นที่ไม่อยู่ในคลังในตัว = ไม่ได้ค่าพวกนี้เลย
   2. ฟิลด์บังคับว่าง → ใช้ค่าเริ่มต้นเงียบ ๆ ไม่เตือน
      ทดสอบจริง: LUNA2000-14-S1 ไม่มี Nominal voltage → โปรแกรมใช้ 400 V · AMCP ไม่มี Max input Voc → 0
   4. EV: Thai_Distributor / Datasheet_URL อยู่ใน ini แต่ไม่ขึ้นเป็นข้อมูลผู้แทนจำหน่ายของอุปกรณ์ (INV/BAT ขึ้น)
   3. Grid_Export_Capable ว่าง = โปรแกรมถือว่า "ขายคืนไม่ได้" (3.4 จึงให้ใส่ True แบบ DERIVED ไว้ก่อน)
