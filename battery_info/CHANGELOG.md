# Battery & System Dashboard — บันทึกการปรับปรุง

สร้างเมื่อ 17 ต.ค. 2569 · โดย ลุงพี
เวอร์ชันปัจจุบันอยู่ใน `VERSION.json` และแสดงท้ายหน้าเว็บ

## v1.1.0 — 19 ต.ค. 2569 · โดย ลุงพี
- **รองรับการเชื่อมต่อผ่านสาย LAN (Ethernet):** เมื่อเสียบสายแลน การ์ด "การเชื่อมต่อ" จะสลับจาก Wi-Fi เป็น LAN อัตโนมัติ แสดงพารามิเตอร์ครบ — ชื่ออแดปเตอร์, ความเร็วลิงก์, โหมดดูเพล็กซ์ (Full/Half), MTU, MAC Address, เวอร์ชันไดรเวอร์, สถานะ
- กล่องสรุปสถานะบอกชนิดการเชื่อมต่อ (สาย LAN พร้อมความเร็ว/ดูเพล็กซ์ หรือ Wi-Fi พร้อมสัญญาณ) และเตือนเมื่อลิงก์เป็น Half Duplex
- เลือกอแดปเตอร์ที่ใช้งานจริงแม่นยำขึ้น: ข้าม Wi-Fi ที่ปิด/หลุด และ VPN tunnel เมื่อสายแลนเป็นลิงก์หลัก
- ไฟล์ SPA พกพาแสดงรายละเอียด LAN เมื่อเปิดคู่กับเซิร์ฟเวอร์ในเครื่อง

## v1.0.0 — 18 ต.ค. 2569 · โดย ลุงพี
- **แดชบอร์ด 3 แท็บในหน้าเดียว** เปิดผ่าน `Battery Terminal.lnk` / `รายงานแบตเตอรี่.lnk` บน Desktop (เริ่ม server ซ่อน + เปิด Edge App mode ครั้งเดียว)
- **แท็บแบตเตอรี่:** สถานะการชาร์จ %, สุขภาพแบตเตอรี่ (บาร์สี แดง/เหลือง/ส้ม/เขียว), รอบชาร์จที่ใช้ไป/เหลือ, คำแนะนำการดูแล, สเปกเครื่อง, รายงาน powercfg ฉบับเต็ม พร้อมเสียงเตือนเมื่อชาร์จเต็มและเมื่อแบตเหลือ ≤20%
- **การ์ดอุณหภูมิ CPU และพัดลมระบายความร้อน:** ประเมินสถานะ (ปกติ/ควรระวัง/ไม่ปกติ/วิกฤต) จากอุณหภูมิ + CPU load + การ throttle พร้อมแนวทางแก้ไข (เครื่องนี้ไม่เปิดค่า RPM ผ่าน WMI จึงเป็นการประเมิน)
- **แท็บโปรแกรม:** โปรแกรมที่ทำงานอยู่ พร้อม CPU/RAM/เวลาทำงาน และแจ้งเตือน (เสียง + แบนเนอร์กะพริบ) โปรแกรมที่ไม่ได้ใช้งานเกินเวลาที่ตั้ง
- **แท็บอินเทอร์เน็ต:** กล่องสรุปสถานะการทำงานพร้อมแนวทางแก้ไข, ทดสอบความเร็ว Download/Upload, Ping/Jitter/Packet loss ตามปลายทาง, DNS, ข้อมูลอแดปเตอร์/IP/Wi-Fi/ปริมาณข้อมูล
- **Wi-Fi ใกล้เคียง 5 อันดับสัญญาณแรงสุด:** เลือกเชื่อมต่อได้ และดูรหัสผ่านรายเครือข่าย เฉพาะ SSID ที่เครื่องนี้เคยเชื่อมและบันทึกไว้ (เหมือน Windows Settings) — endpoint จำกัดเฉพาะหน้าแดชบอร์ดเอง (same-origin) ไฟล์ชั่วคราวเก็บใน `tmp/` และลบทันที
- ระบบ 2 ภาษา ไทย/อังกฤษ และตั้งค่าช่วงรีเฟรชได้ (ค่าเริ่มต้น 10 วินาที) ใช้รีเฟรชเดียวกันทุกแท็บ
- แสดงเวอร์ชันและวันที่ท้ายหน้าเว็บ
