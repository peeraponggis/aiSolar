ช่วยเขียนไฟล์ HTML เพียงไฟล์เดียว (Single Page App) ที่สมบูรณ์ในตัวเอง
สำหรับเปิดด้วยการดับเบิลคลิกบนคอมพิวเตอร์เครื่องใดก็ได้ (Windows/Mac/Linux)
ด้วยเบราว์เซอร์ Chrome หรือ Edge โดยไม่ต้องติดตั้งโปรแกรม ไม่ต้องมีเซิร์ฟเวอร์
และต้องไม่เรียกไลบรารีภายนอกใด ๆ (ไม่มี CDN) — ทุกอย่างอยู่ในไฟล์เดียว
ใช้ HTML + CSS + JavaScript ล้วน

ข้อกำหนดทั่วไป
- รองรับ 2 ภาษา สลับได้ด้วยปุ่ม: ไทย (ค่าเริ่มต้น) และ English
- ธีมมืดเป็นหลัก และรองรับโหมดสว่างตาม prefers-color-scheme
- มีช่องเลือกช่วงรีเฟรชข้อมูล: 5 วินาที, 10 วินาที (ค่าเริ่มต้น), 30 วินาที, 1 นาที
- หน้าจอทำงานได้ดีทั้งบนจอคอมและมือถือ (responsive)
- แบ่งเป็น 3 แท็บ: แบตเตอรี่ / อินเทอร์เน็ต / อุปกรณ์
- ด้านล่างมี footer ว่า: System & Internet Dashboard · v1.0.0

แท็บที่ 1: แบตเตอรี่ (ใช้ Battery Status API: navigator.getBattery)
- วงแหวนแสดงเปอร์เซ็นต์แบต และสีเปลี่ยนตามสถานะ
  (ฟ้า=ใช้งาน, เหลือง=กำลังชาร์จ, เขียว=เต็ม, แดง=เหลือน้อย)
- ป้ายสถานะ: กำลังชาร์จ / ชาร์จเต็มแล้ว / กำลังใช้งาน / แบตต่ำ
- เวลาที่จะชาร์จเต็ม และเวลาใช้งานที่เหลือ (จาก chargingTime/dischargingTime)
- เสียงเตือน (Web Audio API) 2 แบบ:
  * เมื่อชาร์จเต็ม 100% ขณะเสียบปลั๊ก -> เสียงไพเราะเตือนให้ถอดสายชาร์จ
  * เมื่อแบตเหลือ <= 20% และไม่ได้เสียบชาร์จ -> เสียงเตือนเร่งด่วน + แบนเนอร์สีแดงกะพริบ
- ถ้าเบราว์เซอร์ไม่รองรับ Battery API ให้แสดงข้อความแจ้งอย่างสุภาพ
- หมายเหตุใต้การ์ด: สุขภาพแบตและจำนวนรอบชาร์จ เบราว์เซอร์อ่านไม่ได้ (ต้องใช้โปรแกรมในเครื่อง)

แท็บที่ 2: อินเทอร์เน็ต
- กล่อง "สรุปสถานะการทำงาน" ด้านบน: หัวข้อสี เขียว/เหลือง/แดง ตามสุขภาพรวม
  และลิสต์รายการพร้อมไอคอน (✅/⚠️/⛔) และ "แนวทางแก้ไข" สั้น ๆ เป็นภาษาที่คนทั่วไปเข้าใจ
- ปุ่ม "ทดสอบความเร็ว" วัด Download และ Upload โดยใช้ Cloudflare speed endpoint:
  * Download: ยิง https://speed.cloudflare.com/__down?bytes=5000000 พร้อมกันหลายสตรีม (เช่น 4 เส้น)
    แล้วคำนวณ Mbps = ไบต์รวม*8 / วินาที / 1e6
  * Upload: POST ไป https://speed.cloudflare.com/__up ด้วยข้อมูลหลายสตรีม (เช่น 3 เส้น เส้นละ 2MB)
  * เก็บประวัติเป็นกราฟเส้นเล็ก (sparkline) ของ Download/Upload
  * ใช้หลายสตรีมพร้อมกันเพราะเส้นเดียวจะวัดได้ต่ำกว่าความจริงบนเน็ตหน่วงสูง
- การ์ด "หน่วงเวลา (Latency)": วัดเวลาไป-กลับของ fetch ไปยัง
  https://www.cloudflare.com/cdn-cgi/trace (ใส่พารามิเตอร์กันแคช) หน่วยมิลลิวินาที + sparkline
  (หมายเหตุ: เบราว์เซอร์ทำ ICMP ping ไม่ได้ จึงใช้เวลา HTTP round-trip แทน)
- การ์ด "การเชื่อมต่อ": สถานะออนไลน์/ออฟไลน์ (navigator.onLine + event online/offline),
  ประเภทและความเร็วประมาณการจาก navigator.connection (effectiveType, downlink, rtt),
  และ IP สาธารณะ (ดึงจาก https://api.ipify.org?format=json)
- ให้สีของตัวเลขเปลี่ยนตามเกณฑ์ (ความเร็วสูง=เขียว, กลาง=เหลือง, ต่ำ=แดง;
  latency ต่ำ=เขียว, สูง=แดง)

แท็บที่ 3: อุปกรณ์ (ข้อมูลที่เบราว์เซอร์อ่านได้)
- ฮาร์ดแวร์: จำนวนเธรด CPU (navigator.hardwareConcurrency),
  หน่วยความจำโดยประมาณ (navigator.deviceMemory), แพลตฟอร์ม, จำนวนจุดสัมผัส (maxTouchPoints)
- จอแสดงผล: ความละเอียด (screen.width x height), พื้นที่ใช้ได้ (availWidth/Height),
  ความลึกสี (colorDepth), อัตราส่วนพิกเซล (devicePixelRatio)
- ซอฟต์แวร์: ชื่อและเวอร์ชันเบราว์เซอร์ (แยกจาก userAgent), ภาษา (navigator.languages),
  เขตเวลา (Intl.DateTimeFormat), ที่เก็บเบราว์เซอร์ (navigator.storage.estimate -> usage/quota)
- หมายเหตุ: ข้อมูลโปรแกรมที่ทำงาน การใช้ CPU/RAM และอุณหภูมิ ต้องใช้โปรแกรมในเครื่อง
  ไฟล์นี้แสดงได้เฉพาะข้อมูลที่เบราว์เซอร์เข้าถึงได้

ข้อกำหนดด้านเทคนิคและความปลอดภัย
- โค้ดต้องปลอดภัยจาก XSS: ทุกค่าที่นำมาแสดงในตาราง/รายการต้อง escape อักขระ &<>" ก่อน
- ครอบการอ่าน localStorage/sessionStorage และการเล่นเสียงด้วย try/catch
- จัดการกรณี API ไม่รองรับหรือ fetch ล้มเหลวอย่างสุภาพ (แสดง "—" หรือข้อความแจ้ง ไม่ให้หน้าเว็บพัง)
- ใช้สีผ่านตัวแปร CSS (:root) และกำหนดพื้นหลัง body ชัดเจน
- โค้ดสะอาด อ่านง่าย คอมเมนต์เท่าที่จำเป็น

ผลลัพธ์ที่ต้องการ: ตอบกลับเป็นโค้ด HTML เต็มไฟล์เดียว (ตั้งแต่ <!DOCTYPE html> จนจบ </html>)
