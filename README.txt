============================================================
  LOCAL AI — ชุดพกพา (Portable) บน External HDD
============================================================

ระบบ AI แชทในเครื่อง ทำงาน 100% offline ผ่าน Ollama
ทุกอย่างอยู่ในโฟลเดอร์ D:\LocalAI นี้ ย้าย HDD ไปเครื่องอื่นแล้วใช้ได้เลย


------------------------------------------------------------
 สเปคเครื่องที่วิเคราะห์ไว้ (เครื่องต้นทาง)
------------------------------------------------------------
  GPU  : NVIDIA RTX A500 Laptop — VRAM 4GB  (ตัวจำกัดหลัก)
  RAM  : 32GB
  CPU  : Intel i7-1360P

  => VRAM 4GB รันเต็ม GPU ได้แค่โมเดล ~3B
     โมเดล 7B รันแบบ hybrid (GPU+RAM) ได้ ~7-10 tok/s


------------------------------------------------------------
 โครงสร้างไฟล์
------------------------------------------------------------
  D:\LocalAI\
    Start-LocalAI.bat   <- ดับเบิลคลิกเพื่อเริ่มใช้งาน
    ollama\             <- วาง ollama.exe (portable) ที่นี่
    models\             <- โมเดลถูกเก็บที่นี่ (พกไปด้วย)
    ollama-data\        <- config/ประวัติของ ollama (สร้างอัตโนมัติ)
    ui\chat.html        <- หน้าเว็บแชท (เปิดได้ offline)
    chats\              <- ที่เก็บไฟล์ export ประวัติแชท (.json)
    memory\             <- ความจำ/หลักการทำงานของ AI
    README.txt


------------------------------------------------------------
 ติดตั้งครั้งแรก (ทำครั้งเดียว)
------------------------------------------------------------
 1) ดาวน์โหลด Ollama แบบ ZIP (ไม่ใช่ตัว installer):
      https://ollama.com/download/windows
      เลือกไฟล์  ollama-windows-amd64.zip

 2) แตกไฟล์ zip ให้ได้ ollama.exe วางไว้ที่:
      D:\LocalAI\ollama\ollama.exe

 3) ดับเบิลคลิก  lung_pee.bat  (หรือ Start-LocalAI.bat)
      - server จะเริ่มทำงาน + หน้าแชทเปิดในเบราว์เซอร์

 4) ในหน้าต่างสีดำที่เปิดขึ้น พิมพ์ดึงโมเดล (ครั้งแรกเท่านั้น):
      ollama\ollama.exe pull qwen2.5-coder:7b     (โค้ด - ตัวหลัก ~4.7GB)
      ollama\ollama.exe pull qwen2.5-coder:3b     (โค้ด - ตัวเร็ว ~2GB)
      ollama\ollama.exe pull bge-m3               (embedding/RAG/คลังความรู้ ~1.2GB) *จำเป็นสำหรับ RAG
      ollama\ollama.exe pull moondream            (อ่านรูปภาพ vision ~1.7GB, เหมาะ 4GB VRAM)
      # หรือ llava:7b (vision คุณภาพสูงกว่า แต่กิน VRAM มากกว่า)

 5) กลับไปที่หน้าแชท กดปุ่ม ⟳ เพื่อโหลดรายชื่อโมเดล แล้วเริ่มคุยได้เลย


------------------------------------------------------------
 การใช้งานประจำวัน
------------------------------------------------------------
  - ดับเบิลคลิก Start-LocalAI.bat  ->  เริ่มใช้งาน
  - อย่าปิดหน้าต่างสีดำระหว่างใช้งาน (นั่นคือ server)
  - ปิดงาน: ปิดหน้าต่างสีดำได้เลย


------------------------------------------------------------
 ฟีเจอร์ในหน้าแชท (chat.html)
------------------------------------------------------------
  พื้นฐาน:
    - ประวัติแชทหลายห้อง, เลือกโมเดล, สตรีมมิ่ง+หยุด, tok/s, มืด/สว่าง
    - Console (🖥 ด้านล่าง) ย่อ/ขยาย ดู log การทำงานเรียลไทม์
    - คำทักทาย "สวัสดี ลุงพี" + พยากรณ์อากาศวันนี้ (ต้องต่อเน็ต)

  แนบไฟล์ (ปุ่ม 📎 หรือ ลาก-วาง หรือ วางรูป Ctrl+V):
    - รูปภาพ  -> ต้องเลือก vision model (moondream/llava) ก่อน
    - PDF     -> ดึงข้อความอัตโนมัติ (pdf.js บน D:)
    - Excel/CSV/txt -> ดึงข้อความอัตโนมัติ (SheetJS บน D:)

  เสียง:
    - 🎤 พูดเป็นข้อความ (Web Speech - ต้องต่อเน็ตทุกครั้ง)
    - 🔊 อ่านออกเสียง 2 แบบ (เลือกในตั้งค่า -> เครื่องเสียงอ่าน):
        * ในเครื่อง (offline) - เสียง Windows (เช่น Pattara)
        * Neural ออนไลน์ - เปรมวดี(หญิง)/นิวัตน์(ชาย) คุณภาพสูง
          ต้องมี Python + edge-tts + ต่อเน็ต (lung_pee.bat สตาร์ท tts-server.py ให้)
    - ปุ่ม/Esc หยุดอ่านได้

  ลากคลุมข้อความ -> แถบลอย: อ่าน / แปลไทย / คัดลอก / ส่งเข้าแชท

  สร้างสื่อ (พูดสั่งโมเดลได้เลย):
    - กราฟ  -> "วาดกราฟ..." โมเดลตอบบล็อก ```chart เรนเดอร์ Chart.js (offline)
              ต่อข้อมูล AMR: พิมพ์ path ไฟล์ .xls -> อ่าน kWh -> วาดกราฟ
    - รูป   -> "สร้างรูป..." โมเดลตอบบล็อก ```image สร้างด้วย Pollinations (ฟรี/ต่อเน็ต)
    - คลิป  -> "ทำคลิป..." โมเดลตอบบล็อก ```clip -> กดปุ่มสร้าง
              (รูป + เสียง Neural + ffmpeg ต่อเป็น mp4) เก็บที่ clips\
              ต้องมี Python + ffmpeg (tools\ffmpeg\) + ต่อเน็ต

  อ่านไฟล์จาก path: พิมพ์ path ไฟล์/โฟลเดอร์ในข้อความ (เช่น D:\...\x.xls)
    -> backend อ่านให้อัตโนมัติ (text/CSV/Excel/HTML-xls/โฟลเดอร์)

  คลังความรู้ RAG (ปุ่ม 🧠):
    - เก็บเรื่องใหม่/ตรรกะ/สมการ/skill ที่โมเดลไม่รู้ -> ฝังด้วย bge-m3
    - เปิดสวิตช์ 🧠 บนแถบบน -> โมเดลจะดึงความรู้มาประกอบคำตอบ
    - ปุ่ม "💡 จำเข้าคลัง" บนคำตอบ = สอนโมเดลเรื่องนั้น
    - ต้องมีโมเดล bge-m3 + Ollama ทำงานอยู่
    - บันทึกดัชนีลง D: ได้ (knowledge-index.json) เพื่อพกพา

  โมเดลออนไลน์ (ตั้งค่า ⚙ -> ล่างสุด):
    - 🆓 เปิด "โมเดลฟรีออนไลน์ (Pollinations)" = ใช้โมเดลใหญ่/เก่งกว่า local ฟรี ไม่ต้องใช้ key (ต้องต่อเน็ต)
    - 💳 แบบมี API key: กด preset (OpenRouter/Groq/Gemini/OpenAI) แล้วใส่ key
      * แนะนำ OpenRouter/Groq เพราะใช้จากเบราว์เซอร์ได้ (OpenAI/Gemini ตรงๆ อาจติด CORS)
    - เลือกโมเดลจาก dropdown บนสุด (แยกกลุ่ม Local / ฟรี / เสียเงิน)

  ไฟล์ในไดรฟ์ (ปุ่ม 📁, ใช้ Chrome/Edge):
    - เลือกโฟลเดอร์บน D: -> เปิดไฟล์มาทำงานต่อในแชท
    - เปิด "สำรองแชทอัตโนมัติ" -> เขียน chats-backup.json ลงโฟลเดอร์นั้น

------------------------------------------------------------
 ย้ายไปใช้เครื่องอื่น (external HDD)
------------------------------------------------------------
  - เสียบ HDD กับเครื่องใหม่ (เป็นไดรฟ์อะไรก็ได้ E:\ F:\ ...)
  - ดับเบิลคลิก Start-LocalAI.bat ได้เลย — path ปรับตามอัตโนมัติ
  - เงื่อนไข: เครื่องปลายทางควรมี NVIDIA driver ของตัวเอง
    (ถ้าไม่มี GPU/driver จะรันบน CPU อัตโนมัติ ช้าลงแต่ยังใช้ได้)
  - ประวัติแชทผูกกับเบราว์เซอร์ของแต่ละเครื่อง
    ถ้าต้องการพกไปด้วย: กด Export เป็นไฟล์ .json เก็บในโฟลเดอร์ chats\
    แล้วไปกด Import ที่เครื่องใหม่


------------------------------------------------------------
 เคล็ดลับประหยัด VRAM (สำคัญมากกับ 4GB)
------------------------------------------------------------
  ไฟล์ .bat ตั้งค่าเหล่านี้ให้อัตโนมัติแล้ว:
    OLLAMA_FLASH_ATTENTION=1     ลดหน่วยความจำ attention
    OLLAMA_KV_CACHE_TYPE=q8_0    ลดหน่วยความจำ context ลงครึ่ง
    OLLAMA_KEEP_ALIVE=5m         คืน VRAM เมื่อไม่ใช้

  ในหน้าแชท -> ตั้งค่า:
    - num_ctx = 4096  (ค่าแนะนำสำหรับ 4GB; ลดเป็น 2048 ถ้าเครื่องสเปคต่ำกว่า)
    - ปิดเบราว์เซอร์แท็บอื่น/แอปที่เร่ง GPU เพื่อคืน VRAM

  ถ้าย้ายไปเครื่องที่ VRAM น้อยกว่า/ไม่มี GPU:
    - ใช้โมเดล 3B แทน 7B
    - ลด num_ctx เป็น 2048
    - Ollama จะ fallback ไป CPU ให้เอง


------------------------------------------------------------
 ARCHITECTURE การทำงาน (งานเขียนโค้ด / สร้างคลิปสั้น)
------------------------------------------------------------
  ยึดหลัก:  1 Task = 1 Branch = 1 Worktree = 1 PR

    1 Task     = งานย่อยหนึ่งเรื่องจบในตัว (1 ฟีเจอร์ / 1 บั๊ก / 1 คลิป)
    1 Branch   = แตก branch ใหม่ต่อ task เสมอ ไม่ทำบน main โดยตรง
    1 Worktree = ใช้ git worktree แยกโฟลเดอร์ต่อ branch
                 -> ทำหลาย task ขนานกันได้ ไม่ต้องสลับ branch ไปมา
    1 PR       = แต่ละ task ปิดด้วย Pull Request เดียว
                 -> รีวิว/merge แล้วลบ branch + worktree

  ตัวอย่างคำสั่ง:
    git worktree add ../work-task-123 -b feature/task-123
    (ทำงานในโฟลเดอร์นั้น) -> commit -> push -> เปิด PR
    หลัง merge:  git worktree remove ../work-task-123

  ข้อบังคับ: ห้ามเขียนโปรแกรม/โค้ดใดๆ ลง C:\ โดยตรง
             ไฟล์งานทั้งหมดอยู่บน D:\ (หรือไดรฟ์ของ HDD นี้)


------------------------------------------------------------
 แก้ปัญหาเบื้องต้น
------------------------------------------------------------
  หน้าแชทขึ้น "เชื่อมต่อไม่ได้":
    - ตรวจว่าหน้าต่างสีดำ (server) ยังเปิดอยู่
    - กดปุ่ม ⟳ ในหน้าแชท
    - ถ้ายังไม่ได้ ลองปิด .bat แล้วเปิดใหม่

  dropdown ไม่มีโมเดล:
    - ยังไม่ได้ pull โมเดล -> ทำข้อ 4 ด้านบน

  ช้ามาก:
    - โมเดลอาจรันบน CPU ล้วน -> เช็ค nvidia-smi ว่า GPU ถูกใช้
    - ลองโมเดล 3B / ลด num_ctx
