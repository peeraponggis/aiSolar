📘 อ่านก่อนใช้ — ความหมายของป้าย และคู่ที่แนะนำ
  • ฟรีถาวร = โควต้ารีเซ็ตทุกวัน/เดือน · เครดิตทดลอง = ให้ครั้งเดียว/มีวันหมดอายุ · ไม่ฟรีแล้ว = ปิดหรือต้องเติมเงิน
  • 🌐 เรียกจากเว็บได้ ทดสอบ fetch จริงจากเบราว์เซอร์แล้ว (CORS อนุญาต) · ⚠️ ต้องทดสอบ preflight ผ่านแต่คำตอบ error ไม่มี header — ลองด้วย key จริง · 🔒 ต้องผ่าน proxy เบราว์เซอร์ถูกบล็อก ต้องเรียกจากเซิร์ฟเวอร์/สคริปต์
  • 🔐 ต้องเข้าสู่ระบบก่อน ลิงก์สมัครจะพาไปหน้า Login ก่อน (เช่น Typhoon → Sign in with Google → เมนู API Key) เป็นเรื่องปกติ ไม่ใช่ลิงก์เสีย
  • ⭐⭐⭐ ภาษาไทยดีมาก · ⭐⭐ ดี · ⭐ พอใช้ — เป็นการประเมินเชิงแนวทาง ควรลองคำถามไทยจริงก่อนเลือก
  • คู่แนะนำงานไทย: Gemini Flash (หลัก) + Typhoon (งานไทยล้วน/OCR ไทย) + Groq Kimi K2 / gpt-oss (สำรอง เร็ว) — ทั้งสามเรียกจากเว็บได้
  • 🔑 key ที่ใส่ในปุ่ม "ทดสอบ" เก็บใน localStorage ของเครื่องนี้เท่านั้น — ห้ามนำหน้านี้ขึ้นเว็บสาธารณะพร้อม key
  • เงื่อนไขฟรีเปลี่ยนบ่อยโดยไม่แจ้ง — ตัวเลขเป็นข้อมูล ณ ต.ค. 2569 ตรวจหน้าเอกสารทางการก่อนใช้งานจริง
