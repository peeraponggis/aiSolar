## v1.1.0 — 31 ต.ค. 2569 · โดย ลุงพี
- ทดสอบ Kilo Code, Agnes AI, Poolside ด้วย endpoint ทางการแล้ว:
  - Kilo AI Gateway `ai-gateway.kilo.ai/api/v1` — ใช้ได้โดยไม่ต้องมี key (200 req/ชม. ต่อ IP) ตอบภาษาไทยได้ แต่เบราว์เซอร์ถูกบล็อก CORS
  - Agnes AI `apihub.agnes-ai.com/v1` — เรียกจากเว็บได้ (รุ่น agnes-2.0-flash)
  - Poolside `inference.poolside.ai/v1` — เรียกจากเว็บได้ (รุ่น poolside/laguna-s-2.1) · สมัครที่ platform.poolside.ai
- ปุ่ม 📋 คำสั่งทดสอบ ทุกเจ้าที่มี Base URL: คำสั่ง PowerShell / Python / curl สำหรับทดสอบนอกเบราว์เซอร์ (ใช้กับเจ้าที่ติด CORS) — ทดสอบรันจริงกับ Kilo แล้ว ภาษาไทยแสดงถูกต้องทั้ง PowerShell 5.1 และ Python
- ป้าย/ตัวกรอง 🆓 ใช้ได้ไม่ต้องมี key (OVHcloud, Kilo)

## v1.0.0 — 31 ต.ค. 2569 · โดย ลุงพี
- SPA ไฟล์เดียว รวมผู้ให้บริการ AI API ฟรี/มีโควต้า 87 ราย แบ่งหมวด: LLM ฟรี · สายไทย · เครดิตทดลอง · Embedding · เสียง · OCR/ภาพ · ไม่ฟรีแล้ว
- ทุกการ์ดมี โควต้าฟรี · ต้องผูกบัตร/ยืนยันเบอร์ไหม · ลิงก์สมัคร API key · เอกสาร · Base URL (คัดลอกได้)
- ดาวภาษาไทย ⭐–⭐⭐⭐ พร้อมชื่อรุ่นที่ใช้ภาษาไทยได้ดี
- ป้าย CORS จากการทดสอบ fetch จริงในเบราว์เซอร์ (🌐 เรียกจากเว็บได้ / ⚠️ ต้องทดสอบ / 🔒 ต้องผ่าน proxy)
- ตรวจลิงก์สมัครทุกลิงก์ 31 ต.ค. 2569 — แก้ลิงก์ที่ย้าย (Fireworks, Nebius, ElevenLabs) ย้าย iApp/AI21 ไปกลุ่มไม่ฟรีแล้ว
- ปุ่ม 🧪 ทดสอบ key (OpenAI-compatible) ส่งข้อความไทยดูคำตอบจริง · ดึงรายชื่อรุ่น · ⚡ ทดสอบ key ทั้งหมด
- ค้นหา · ตัวกรอง (ฟรีถาวร, ไม่ผูกบัตร, ไทย ⭐⭐⭐, เรียกจากเว็บได้, สมัครแล้ว) · เรียงลำดับ
- ติ๊ก "สมัครแล้ว" + บันทึกส่วนตัว · สำรอง/นำเข้า (ไม่รวม key) · ธีมสว่าง/มืด · PDPA modal
