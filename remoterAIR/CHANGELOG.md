# CHANGELOG — RemoteAIR โดย ลุงพี

## [1.0.0] — 2026-10-27
### เพิ่ม
- Flutter app ข้ามแพลตฟอร์ม (Android / iOS)
- สแกนและบันทึกสัญญาณ IR จากรีโมทเดิม
- รองรับแอร์หลายเครื่อง ตั้งชื่อเองได้
- ปรับอุณหภูมิ 16–30 °C, โหมด Cool/Heat/Fan/Dry/Auto
- ความเร็วพัดลม Auto/1–4
- ตั้งเวลาเปิด-ปิด (Timer on/off)
- แดชบอร์ดแสดงพารามิเตอร์แอร์ทุกตัว
- ESP8266 firmware สำหรับ IR bridge (AP setup + STA mode)
- สร้าง QR code สำหรับติดตั้งแอป
